# রাকিব সাবটাইটেল

যেকোনো স্ক্রিপ্ট → রাকিব কণ্ঠের অডিও + সময় মিলিয়ে সাবটাইটেল (SRT / JSON)।

ASR (অডিও শুনে লেখা বের করা) কোথাও ব্যবহার করা হয় না — লেখা সবসময় আপনার
স্ক্রিপ্টেরটাই থাকে, তাই বাংলা ১০০% সঠিক। সময় আসে অডিও থেকে।

## তিনটি পথ

- **A. স্ক্রিপ্ট → অডিও + সাবটাইটেল (সবচেয়ে নির্ভুল):** স্ক্রিপ্ট পেস্ট করুন,
  রাকিব মডেল প্রতি বাক্য আলাদা করে বানায়, প্রতিটার আসল সময় মেপে SRT/JSON
  বানায়। সাথে জোড়া দেওয়া WAV অডিওও ডাউনলোড করা যায়।
- **B. অডিও + স্ক্রিপ্ট → সাবটাইটেল:** আগে বানানো রাকিব অডিও আপলোড করুন আর
  স্ক্রিপ্ট পেস্ট করুন। অডিওর নীরবতা (বাক্যের ফাঁকের ০.৫ সেকেন্ড) ধরে বাক্যের
  সীমানা মেলানো হয়। পরীক্ষায় ৭টি বাক্যে সবচেয়ে বেশি ভুল ০.১৪ সেকেন্ড।
- **C. স্ক্রিপ্ট + মোট সময় → সাবটাইটেল (আনুমানিক):** অডিও না থাকলে মোট
  সময় (কত মিনিট) দিলে বাক্যের দৈর্ঘ্য অনুযায়ী ভাগ করে দেওয়া হয়।

## ফাইল

- `app.py` — Streamlit UI (বাংলা)
- `subtitle_tools.py` — বাক্য ভাগ, নীরবতা ধরে সীমানা, SRT/JSON, আনুমানিক ভাগ
- `tts_engine.py` — রাকিব TTS ইঞ্জিন (sherpa-onnx; মডেল HF থেকে নামে, MD5 মিলিয়ে)
